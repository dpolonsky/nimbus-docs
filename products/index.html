Nimbus Docs › Products › Pairing key

Pairing key

ModelFirmwareKey on update
X1002.xFirmware 2.x keeps the pairing key across updates. After an update the unit reconnects on its own and no re-pairing is needed.
X2003.xThe 3.x update resets the unit's pairing key. The app keeps the old key, so the unit shows Offline and every handshake is rejected with E42. Re-pairing is expected.
X3004.xThe 4.x update keeps the pairing key but re-issues the cloud token. The unit stays paired locally; the app asks the user to sign in again, and until then it shows Cloud Offline (error E61).
X4004.xThe pairing key is kept on 4.0 but reset once on the update from 4.0 to 4.1. After that, later 4.x updates keep the key.
X5005.xFirmware 5.x rotates the pairing key silently on every update and the app picks up the new key by itself. No user action is needed; if the unit shows Offline afterwards it is a fault (E77).
