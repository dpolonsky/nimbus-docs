Which guide applies to me

If the About screen shows firmware 2.x, use the pages under X100. If it shows 3.x, use the pages under X200. Troubleshooting guides name their model in the first line.

Nimbus Docs › Products › Glossary

Glossary

Terms used across the documentation.

Nimbus Docs › Products › Glossary › Pairing key

Pairing key

A secret shared by the unit and the app after pairing. If the two copies differ the unit is rejected and the app reports E42.

Nimbus Docs › Products › Glossary › Pairing mode

Pairing mode

A 60 second window in which the unit accepts a new pairing. The LED blinks (green on X100, white on X200).

Nimbus Docs › Products › Glossary › Factory reset

Factory reset

Erases settings and the pairing key. See Factory Reset Procedure.

Nimbus Docs › Products › Glossary › Firmware line

Firmware line

The major version family that belongs to a model: 2.x for the X100, 3.x for the X200. Lines are not interchangeable.

Nimbus Docs › Products › Support lifecycle

Support lifecycle

The X100 and X200 are supported. The X50 (firmware 1.x) is retired; it is not covered here.
