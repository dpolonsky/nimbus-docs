X100 Firmware 2.x Release Notes

Product: X100 · Firmware: 2.x · Status: published · Updated: 2026-10-25

Nimbus Docs › Products › X100 Overview › X100 Firmware 2.x Release Notes › Behaviour that matters for support

Behaviour that matters for support

Two behaviours drive most X100 support cases.

Nimbus Docs › Products › X100 Overview › X100 Firmware 2.x Release Notes › Behaviour that matters for support › The pairing key is preserved

The pairing key is preserved

Firmware 2.x keeps the pairing key across updates. After an update the unit reconnects on its own and no re-pairing is needed. This is different from the X200, see X200 key reset.

Nimbus Docs › Products › X100 Overview › X100 Firmware 2.x Release Notes › Behaviour that matters for support › Update prerequisites

Update prerequisites

The update needs at least 50 percent charge or a connected USB-C supply. Below that it aborts with E17.

Nimbus Docs › Products › X100 Overview › X100 Firmware 2.x Release Notes › How to update

How to update

  1. Connect the unit to USB-C power.
  2. In the app open Devices → About → Update.
  3. Wait for the LED to stop being amber. This takes up to 10 minutes.
  4. Check About: the firmware line shows the new version.

Known issues

If a customer reports having to pair again after a 2.x update, treat it as a fault. Forget the device on both sides and pair again with the X100 pairing steps.
