X100 Overview

Product: X100 · Firmware: 2.x · Status: published · Updated: 2026-10-25

Nimbus Docs › Products › X100 Overview › Overview

Overview

The X100 is the first-generation Nimbus unit. It ships with firmware 2.x and is paired from its own Settings menu rather than from the app. Its pairing key is stored on the unit and survives firmware updates.

Nimbus Docs › Products › X100 Overview › How pairing works on the X100

How pairing works on the X100

The unit initiates pairing; the app only confirms it.

Nimbus Docs › Products › X100 Overview › How pairing works on the X100 › Pairing flow

Pairing flow

  1. On the unit open Settings → Bluetooth → Pair new device. The LED blinks green.
  2. In the app choose the unit from the list that appears.
  3. Confirm the 6 digit code on both screens within 60 seconds.

Nimbus Docs › Products › X100 Overview › How pairing works on the X100 › What persists

What persists

The pairing key stays on the unit across firmware updates, restarts and Wi-Fi changes. Only a factory reset or Forget device removes it. See firmware 2.x key behaviour.

Nimbus Docs › Products › X100 Overview › Care and maintenance

Care and maintenance

Routine care keeps connectivity problems away.

Nimbus Docs › Products › X100 Overview › Care and maintenance › Placement

Placement

Keep the unit at least 1 m from other electronics and 2 m from a microwave oven. The X100 radios on 2.4 GHz, which is the band microwaves disturb. See causes of Wi-Fi dropouts.

Nimbus Docs › Products › X100 Overview › Care and maintenance › Power

Power

Use the supplied 5 V / 2 A USB-C adapter. A weaker supply is the most common cause of E17 during updates.

Nimbus Docs › Products › X100 Overview › When to contact support

When to contact support

Contact support after one retry of the matching guide has failed. Have ready: the firmware version, the LED state and colour, any error code and the router model. See what to collect.
