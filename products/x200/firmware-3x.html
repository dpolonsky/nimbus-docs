X200 Firmware 3.x Release Notes

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-11-09

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › Behaviour that matters for support

Behaviour that matters for support

The 3.x update resets the unit's pairing key. The app keeps the old key, so the unit shows Offline and every handshake is rejected with E42. Re-pairing is expected.

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › Update prerequisites

Update prerequisites

The update needs at least 50 percent charge or a connected USB-C supply of 3 A. Below that it aborts with E17.

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › How to update

How to update

  1. Connect the unit to USB-C power.
  2. In the app open Devices → About → Update.
  3. Wait for the LED to stop being amber. This takes up to 12 minutes.
  4. Check About: the firmware line shows the new version.

Rollback

Rollback from 3.x to 2.x is not supported, see Firmware Rollback.
