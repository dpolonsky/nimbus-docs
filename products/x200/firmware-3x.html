X200 Firmware 3.x Release Notes

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-10-25

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › The 3.x update resets the pairing key

The 3.x update resets the pairing key

This is the single most important behaviour of firmware 3.x.

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › The 3.x update resets the pairing key › Why it happens

Why it happens

Firmware 3.0 introduced a new pairing flow with per-install keys. Each update regenerates the unit key so a lost phone cannot keep access across updates.

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › The 3.x update resets the pairing key › What you will see

What you will see

After the update the app still holds the old key, so the unit appears Offline, the LED stays white and pairing from the app may fail with E42.

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › The 3.x update resets the pairing key › What to do

What to do

  1. Wait until the LED is no longer amber.
  2. Follow Re-enable Pairing Mode.
  3. If E42 persists, run the Factory Reset Procedure.

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › The update process

The update process

  1. Connect USB-C power (3 A).
  2. Start the update from Devices → About → Update. Since 3.2 the app warns that re-pairing will be needed.
  3. The LED is amber for up to 10 minutes. Do not unplug.
  4. The unit restarts and shows white.

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › Rollback

Rollback

Going back to 2.x is not supported. See Firmware Rollback.

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › Known issues

Known issues

On 3.0 the app did not announce the key reset, so customers saw an unexplained Offline state. Update to 3.2 or later to get the warning.
