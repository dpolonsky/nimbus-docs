What changed

X200 firmware 3.4: Improves 5 GHz roaming.

Updating to 3.4

Update from Devices → About → Update. Keep the unit on USB-C power. See X200 release notes.

Nimbus Docs › Products › X200 Overview › X200 Firmware 3.x Release Notes › X200 Firmware 3.4 › Pairing impact

Pairing impact

The 3.4 update resets the unit's pairing key. The app keeps the old key, so the unit shows Offline and every handshake is rejected with E42. Re-pairing is expected.
