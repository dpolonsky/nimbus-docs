X200 Overview

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-10-25

The X200 is the current Nimbus unit. It runs firmware 3.x and is paired from the Nimbus app.

Key facts

  • Pairing is initiated in the app: Devices → Add device, or Enable pairing mode for a known unit.
  • The 3.x update resets the pairing key. After every 3.x update the unit must be paired again.
  • Factory reset is done with the power button (hold 15 seconds), see Factory Reset Procedure.

If the unit will not pair after an update, start with Pairing (X200).
