X200 Overview

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-10-25

Nimbus Docs › Products › X200 Overview › Overview

Overview

The X200 is the current Nimbus unit. It runs firmware 3.x and is paired from the Nimbus app. Unlike the X100, every 3.x firmware update resets its pairing key, so the unit has to be paired again after updating.

Nimbus Docs › Products › X200 Overview › How pairing works on the X200

How pairing works on the X200

The app initiates pairing; the unit only enters pairing mode.

Nimbus Docs › Products › X200 Overview › How pairing works on the X200 › Pairing flow

Pairing flow

  1. In the app open Devices → Add device, or select the unit and tap Enable pairing mode.
  2. The unit LED blinks white.
  3. Confirm the 6 digit code on both screens within 60 seconds.

Nimbus Docs › Products › X200 Overview › How pairing works on the X200 › What persists

What persists

The key survives restarts and Wi-Fi changes but not firmware updates. See the 3.x key reset.

Nimbus Docs › Products › X200 Overview › Care and maintenance

Care and maintenance

Use the supplied 5 V / 3 A USB-C adapter. The X200 can use both Wi-Fi bands; if it drops off a mesh network, see the X200 Wi-Fi steps.

Nimbus Docs › Products › X200 Overview › When to contact support

When to contact support

Run the matching guide once. For pairing failures that persist after a factory reset, contact support with the firmware version, LED colour and the error code.
