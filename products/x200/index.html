X200 Overview

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-11-09

Nimbus Docs › Products › X200 Overview › Summary

Summary

The X200 runs firmware 3.x. It uses Bluetooth 5.3 with about 25 m range and supply 3 A over USB-C.

Nimbus Docs › Products › X200 Overview › How pairing works on the X200

How pairing works on the X200

Pairing uses a 6 digit code with a 60 second window. The 3.x update resets the unit's pairing key. The app keeps the old key, so the unit shows Offline and every handshake is rejected with E42. Re-pairing is expected. See X200 firmware notes and pairing troubleshooting.

Nimbus Docs › Products › X200 Overview › Power

Power

Use the supplied 3 A USB-C adapter. A weaker supply causes E17 and E90.

Nimbus Docs › Products › X200 Overview › Factory reset

Factory reset

To reset the X200, hold the power button for 15 seconds until the LED blinks red. Full steps: X200 factory reset.
