X300 Firmware 4.x Release Notes

Product: X300 · Firmware: 4.x · Status: published · Updated: 2026-11-09

Nimbus Docs › Products › X300 Overview › X300 Firmware 4.x Release Notes › Behaviour that matters for support

Behaviour that matters for support

The 4.x update keeps the pairing key but re-issues the cloud token. The unit stays paired locally; the app asks the user to sign in again, and until then it shows Cloud Offline (error E61).

Nimbus Docs › Products › X300 Overview › X300 Firmware 4.x Release Notes › Update prerequisites

Update prerequisites

The update needs at least 50 percent charge or a connected USB-C supply of 3 A. Below that it aborts with E17.

Nimbus Docs › Products › X300 Overview › X300 Firmware 4.x Release Notes › How to update

How to update

  1. Connect the unit to USB-C power.
  2. In the app open Devices → About → Update.
  3. Wait for the LED to stop being amber. This takes up to 14 minutes.
  4. Check About: the firmware line shows the new version.

Rollback

Rollback to an earlier firmware line is blocked and shows E58.

Nimbus Docs › Products › X300 Overview › X300 Firmware 4.x Release Notes › Known issues

Known issues

After the update expect E61 until the cloud account is re-linked.
