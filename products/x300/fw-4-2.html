What changed

X300 firmware 4.2: Fixes cloud token refresh loop.

Nimbus Docs › Products › X300 Overview › X300 Firmware 4.x Release Notes › X300 Firmware 4.2 › Updating to 4.2

Updating to 4.2

Update from Devices → About → Update. Keep the unit on USB-C power. See X300 release notes.

Nimbus Docs › Products › X300 Overview › X300 Firmware 4.x Release Notes › X300 Firmware 4.2 › Pairing impact

Pairing impact

The 4.2 update keeps the pairing key but re-issues the cloud token. The unit stays paired locally; the app asks the user to sign in again, and until then it shows Cloud Offline (error E61).
