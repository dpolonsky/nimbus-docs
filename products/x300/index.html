X300 Overview

Product: X300 · Firmware: 4.x · Status: published · Updated: 2026-11-09

Nimbus Docs › Products › X300 Overview › Summary

Summary

The X300 runs firmware 4.x. It uses Bluetooth 5.3 with about 30 m range and supply 3 A over USB-C.

Nimbus Docs › Products › X300 Overview › How pairing works on the X300

How pairing works on the X300

Pairing uses a 6 digit code with a 60 second window. The 4.x update keeps the pairing key but re-issues the cloud token. The unit stays paired locally; the app asks the user to sign in again, and until then it shows Cloud Offline (error E61). See X300 firmware notes and pairing troubleshooting.

What persists

Nimbus Docs › Products › X300 Overview › Power

Power

Use the supplied 3 A USB-C adapter. A weaker supply causes E17 and E90.

Nimbus Docs › Products › X300 Overview › Factory reset

Factory reset

To reset the X300, hold the power button for 10 seconds until the LED blinks purple. Full steps: X300 factory reset.
