Updating to 5.0

Update from Devices → About → Update. Keep the unit on USB-C power. See X500 release notes.

Nimbus Docs › Products › X500 Overview › X500 Firmware 5.x Release Notes › X500 Firmware 5.0 › Pairing impact

Pairing impact

Firmware 5.0 rotates the pairing key silently on every update and the app picks up the new key by itself. No user action is needed; if the unit shows Offline afterwards it is a fault (E77).
