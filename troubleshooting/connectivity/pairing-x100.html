Pairing (X100, firmware 2.x)

Product: X100 · Firmware: 2.x · Status: published · Updated: 2026-10-25

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X100, firmware 2.x) › Applies to

Applies to

X100, firmware 2.x only. For the X200 use Pairing (X200).

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X100, firmware 2.x) › Symptoms

Symptoms

  • The unit is not listed in the app.
  • The unit is listed but shows Offline.
  • Pairing starts and times out after 60 seconds.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X100, firmware 2.x) › Likely causes

Likely causes

In order of frequency.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X100, firmware 2.x) › Likely causes › A stale pairing entry

A stale pairing entry

The phone or the unit still holds an entry from an earlier pairing. Both sides must forget it.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X100, firmware 2.x) › Likely causes › Range or sleep

Range or sleep

The X100 uses Bluetooth 4.2 with about 10 m of range. Keep the phone within 3 m during pairing. A sleeping unit may need a button press to wake.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X100, firmware 2.x) › Likely causes › Revoked permission

Revoked permission

If Bluetooth permission was revoked for the app, it cannot discover the unit.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X100, firmware 2.x) › Steps

Steps

  1. On the unit open Settings → Bluetooth and choose Forget device for the old phone entry.
  2. On the phone forget the Nimbus X100 in system Bluetooth settings.
  3. Restart the unit: hold the power button for 5 seconds.
  4. On the unit open Settings → Bluetooth → Pair new device. The LED blinks green.
  5. Within 60 seconds select the unit in the app and confirm the 6 digit code on both screens.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X100, firmware 2.x) › Verify

Verify

The LED turns steady green and the app shows the unit Online.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X100, firmware 2.x) › If it still fails

If it still fails

Retry once with the phone within 3 m. Then reset from Settings → System → Reset (see X100 reset) and contact support with the firmware version. Remember that 2.x does not reset pairing on update, see key preserved.
