Pairing (X200, firmware 3.x)

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-11-09

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Applies to

Applies to

X200, firmware 3.x only. Other models: Connectivity.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Symptoms

Symptoms

  • The X200 is not listed in the app.
  • The unit is listed but shows Offline.
  • Pairing starts and times out after 60 seconds.
  • The app shows E42.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Likely causes

Likely causes

  • A stale pairing entry on the phone or the unit.
  • Range: the X200 uses Bluetooth 5.3 with about 25 m; keep the phone within 3 m.
  • Revoked Bluetooth permission, see Grant Bluetooth Permission.
  • The 3.x update reset the unit key while the app kept the old key, see E42.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Steps

Steps

  1. Run Re-enable Pairing Mode.
  2. If E42 persists run the Factory Reset Procedure.
  3. Within 60 seconds confirm the 6 digit code on both screens.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Verify

Verify

The LED turns steady white and the app shows the unit Online.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › If it still fails

If it still fails

Reset the unit: X200 factory reset. The 3.x update resets the unit's pairing key. The app keeps the old key, so the unit shows Offline and every handshake is rejected with E42. Re-pairing is expected. Then contact support.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Do not

Do not

Do not follow the steps of another model. The X200 has no Forget device menu entry. Do not try to roll back the firmware, see Firmware Rollback.
