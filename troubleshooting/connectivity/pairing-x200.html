Pairing (X200, firmware 3.x)

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-10-25

Applies to: X200, firmware 3.x only. For X100 use Pairing (X100).

Symptoms

  • "My X200 won't pair with the app after the update."
  • Unit shows Offline in the app, LED is white steady.
  • App shows error E42 when pairing.

Cause

On X200 (firmware 3.x) the update resets the pairing key. The app still holds the old key, so the unit is rejected until the pairing is renewed. See X200 Firmware 3.x Release Notes.

Steps

  1. Confirm the update has finished: the LED must not be amber.
  2. Re-enable pairing mode in the app, following Re-enable Pairing Mode. The LED blinks white.
  3. Pair the unit with the app and confirm the code shown on both.
  4. If error E42 persists after two attempts, run the Factory Reset Procedure and pair again.

Verify

LED steady white, app shows Online, and About → Pairing key shows a date of today.

Do not

  • Do not follow X100 steps (forget device in the unit's Settings menu). The X200 has no such menu entry.
  • Do not attempt a firmware rollback; it is not supported, see Firmware Rollback.
