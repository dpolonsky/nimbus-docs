Pairing (X200, firmware 3.x)

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-10-25

On X200 (firmware 3.x) the update resets the pairing key. Re-enable pairing mode in the app, then pair. If error E42 persists, run the Factory reset procedure.
