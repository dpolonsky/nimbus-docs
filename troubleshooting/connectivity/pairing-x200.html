Pairing (X200, firmware 3.x)

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-10-25

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Applies to

Applies to

X200, firmware 3.x only. For the X100 use Pairing (X100).

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Symptoms

Symptoms

  • “My X200 won’t pair with the app after the update.”
  • Unit shows Offline in the app while the LED is steady white.
  • Pairing fails with error E42.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Cause

Cause

On X200 (firmware 3.x) the update resets the pairing key. The app still holds the old key, so the unit is rejected until the pairing is renewed. The behaviour is documented in X200 Firmware 3.x Release Notes.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Cause › Why the key and the app disagree

Why the key and the app disagree

The update generates a new key on the unit but cannot reach the app to replace its copy. The two copies differ, so the handshake fails and the unit is shown Offline.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Cause › What it is not

What it is not

It is not a Wi-Fi fault and not a hardware fault. The unit is online and reachable by the router. Do not follow Wi-Fi Dropouts for this symptom.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Steps

Steps

  1. Confirm the update has finished: the LED is not amber.
  2. Re-enable pairing mode in the app with Re-enable Pairing Mode. The LED blinks white.
  3. Pair and confirm the 6 digit code on both screens.
  4. If E42 persists after two attempts, run the Factory Reset Procedure and pair again.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Verify

Verify

LED steady white, the app shows Online, and About → Pairing key shows today’s date.

Nimbus Docs › Troubleshooting › Connectivity › Pairing (X200, firmware 3.x) › Do not

Do not

  • Do not follow the X100 steps (forget device in the unit’s own Settings menu). The X200 has no such menu entry.
  • Do not try to roll back the firmware; it is not supported, see Firmware Rollback.
