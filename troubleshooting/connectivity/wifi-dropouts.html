Wi-Fi Dropouts

Product: All · Firmware: - · Status: published · Updated: 2026-10-25

Applies to: X100 and X200.

Symptoms

  • Unit goes Offline every few minutes and comes back by itself.
  • Streaming stutters, then recovers.

Likely causes, in order of frequency

  1. 2.4 GHz interference from microwaves, cordless phones or neighbouring routers.
  2. Router set to 5 GHz only. The X100 supports 2.4 GHz only.
  3. Router channel 12 to 14, which some units do not scan.
  4. Router band steering moving the unit between bands.

Steps

  1. Move the unit at least 1 m away from other electronics and 2 m from a microwave.
  2. In the router set the 2.4 GHz channel to 1, 6 or 11 (not Auto) and the width to 20 MHz.
  3. X100 only: make sure the 2.4 GHz band is enabled and has its own SSID.
  4. X200 only: if roaming between mesh nodes causes drops, pin the unit to the nearest node, or update to firmware 3.1 or later which improves 5 GHz roaming.
  5. Restart the router, then the unit.

Verify

The unit stays Online for 30 minutes. If it still drops, note the time of each drop and contact support; this is not a pairing issue, so a factory reset will not help.
