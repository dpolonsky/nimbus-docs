Wi-Fi Dropouts

Product: All · Firmware: - · Status: published · Updated: 2026-10-25

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Applies to

Applies to

X100 and X200. Steps are split by model where they differ.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Symptoms

Symptoms

  • The unit goes Offline for a few minutes and comes back by itself.
  • The unit appears and disappears in the router client list.
  • Streaming stutters and recovers.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Likely causes

Likely causes

In order of frequency.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Likely causes › 2.4 GHz interference

2.4 GHz interference

Microwave ovens, cordless phones and neighbouring routers share the 2.4 GHz band. The X100 uses only this band.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Likely causes › Router on 5 GHz only

Router on 5 GHz only

The X100 cannot see 5 GHz. A router that broadcasts only on 5 GHz makes the unit invisible. The X200 supports both.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Likely causes › Router channel 12 to 14

Router channel 12 to 14

Some units do not scan channels above 11. Use 1, 6 or 11.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Likely causes › Band steering and mesh roaming

Band steering and mesh roaming

Routers that move clients between bands or mesh nodes can drop the connection mid-move. Mostly affects the X200 on firmware before 3.1.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Steps

Steps

Do the common steps first, then the model steps.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Steps › Common steps

Common steps

  1. Move the unit at least 1 m from other electronics and 2 m from a microwave.
  2. Set the router 2.4 GHz channel to 1, 6 or 11 (not Auto) and the width to 20 MHz.
  3. Restart the router, then the unit.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Steps › X100 only

X100 only

Make sure the router has the 2.4 GHz band enabled with its own SSID so the unit does not get steered.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Steps › X200 only

X200 only

Pin the unit to the nearest mesh node, or update to firmware 3.1 or later, which improves 5 GHz roaming. See 3.x version history.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › Verify

Verify

The unit stays Online for 30 minutes.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › What does not help

What does not help

A factory reset does not fix Wi-Fi dropouts: the pairing is intact, only the radio link is unstable. Compare with pairing causes, where a reset does help.

Nimbus Docs › Troubleshooting › Connectivity › Wi-Fi Dropouts › When to escalate

When to escalate

If the unit still drops after the steps, note the time of each drop and the router model and contact support.
