Error E17: Low Battery During Update

Product: All · Firmware: - · Status: published · Updated: 2026-11-09

Nimbus Docs › Troubleshooting › Error Codes › Error E17: Low Battery During Update › Meaning

Meaning

E17, low battery during update. The firmware update stopped because the battery fell below 50 percent, or power was lost during the update.

Nimbus Docs › Troubleshooting › Error Codes › Error E17: Low Battery During Update › Applies to

Applies to

all models.

Nimbus Docs › Troubleshooting › Error Codes › Error E17: Low Battery During Update › Causes

Causes

  • Unit not on USB-C power
  • Weak adapter: X100 needs 2 A, X200 needs 3 A
  • A faulty cable

Nimbus Docs › Troubleshooting › Error Codes › Error E17: Low Battery During Update › Steps

Steps

  1. Connect the unit to the supplied USB-C adapter
  2. Wait until the app shows at least 50 percent
  3. Start the update again from Devices → About → Update

Nimbus Docs › Troubleshooting › Error Codes › Error E17: Low Battery During Update › After a successful X200 update

After a successful X200 update

The X200 3.x update resets the pairing key, so expect to pair again. See the 3.x key reset and E42.

Nimbus Docs › Troubleshooting › Error Codes › Error E17: Low Battery During Update › Procedures

Procedures

See USB-C Cable and Adapter Test.

Nimbus Docs › Troubleshooting › Error Codes › Error E17: Low Battery During Update › Verify

Verify

The app shows the unit Online and the code does not return after 10 minutes.
