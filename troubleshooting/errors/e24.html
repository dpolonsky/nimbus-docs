Error E24: Certificate Expired

Product: All · Firmware: - · Status: published · Updated: 2026-11-09

Nimbus Docs › Troubleshooting › Error Codes › Error E24: Certificate Expired › Meaning

Meaning

E24, certificate expired. The unit certificate expired and cloud calls are rejected.

Nimbus Docs › Troubleshooting › Error Codes › Error E24: Certificate Expired › Applies to

Applies to

all models.

Nimbus Docs › Troubleshooting › Error Codes › Error E24: Certificate Expired › Causes

Causes

  • Unit offline for more than 90 days
  • Clock wrong

Nimbus Docs › Troubleshooting › Error Codes › Error E24: Certificate Expired › Steps

Steps

  1. Connect the unit for 10 minutes
  2. Fix the time first (E23)

Nimbus Docs › Troubleshooting › Error Codes › Error E24: Certificate Expired › Procedures

Procedures

See Update the Nimbus App.

Nimbus Docs › Troubleshooting › Error Codes › Error E24: Certificate Expired › Verify

Verify

The app shows the unit Online and the code does not return after 10 minutes.
