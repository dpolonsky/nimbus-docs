Error E42: Pairing Key Mismatch

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-11-09

Nimbus Docs › Troubleshooting › Error Codes › Error E42: Pairing Key Mismatch › Meaning

Meaning

E42, pairing key mismatch. The app and the unit hold different pairing keys. Applies to X200 firmware 3.x.

Nimbus Docs › Troubleshooting › Error Codes › Error E42: Pairing Key Mismatch › Applies to

Applies to

X200.

Nimbus Docs › Troubleshooting › Error Codes › Error E42: Pairing Key Mismatch › Why it happens

Why it happens

The 3.x update resets the unit's key, see the 3.x key reset. The app keeps the old key, so every handshake is rejected with E42. The user-facing symptom is described in Pairing (X200), Cause.

Nimbus Docs › Troubleshooting › Error Codes › Error E42: Pairing Key Mismatch › Causes

Causes

  • The 3.x update resets the unit's key but the app keeps the old key

Nimbus Docs › Troubleshooting › Error Codes › Error E42: Pairing Key Mismatch › Steps

Steps

  1. Re-enable pairing mode and pair again, try this twice
  2. In the app choose Devices → unit → Remove
  3. Run the Factory Reset Procedure
  4. Add the unit as new

Nimbus Docs › Troubleshooting › Error Codes › Error E42: Pairing Key Mismatch › Procedures

Procedures

See Re-enable Pairing Mode, Factory Reset Procedure.

Nimbus Docs › Troubleshooting › Error Codes › Error E42: Pairing Key Mismatch › Verify

Verify

The app shows the unit Online and the code does not return after 10 minutes.

Nimbus Docs › Troubleshooting › Error Codes › Error E42: Pairing Key Mismatch › Related errors

Related errors

See also E17: Low Battery During Update.

Nimbus Docs › Troubleshooting › Error Codes › Error E42: Pairing Key Mismatch › Prevention

Prevention

Update to 3.2 or later: the app warns before the key reset. After any 3.x update, run Re-enable Pairing Mode immediately.
