How error codes work

Error codes appear in the Nimbus app and in the unit log. The code number is stable; the wording can change between app versions.

Nimbus Docs › Troubleshooting › Error Codes › Reading a code in the app

Reading a code in the app

Open Devices → your unit → Status. The most recent code is shown with a time stamp. Codes older than 7 days are archived.
