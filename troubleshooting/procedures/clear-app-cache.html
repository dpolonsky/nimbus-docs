Clear App Cache

Product: all models · Firmware: - · Status: published · Updated: 2026-11-09

Nimbus Docs › Troubleshooting › Procedures › Clear App Cache › Before you start

Before you start

Applies to all models. Clearing the cache does not remove paired units. It takes about 30 seconds.

Nimbus Docs › Troubleshooting › Procedures › Clear App Cache › Steps

Steps

  1. Open the phone settings and find the Nimbus app.
  2. Choose Storage → Clear cache (not Clear data).
  3. Reopen the app and pull down to refresh the device list.

Nimbus Docs › Troubleshooting › Procedures › Clear App Cache › Result

Result

If it does not help, contact support.
