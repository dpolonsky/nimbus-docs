Factory Reset (X400)

Product: X400 · Firmware: 4.x · Status: published · Updated: 2026-11-09

Nimbus Docs › Troubleshooting › Procedures › Factory Reset (X400) › Before you start

Before you start

This erases local settings, saved Wi-Fi networks and the pairing key. Cloud data is not affected. Remove the unit in the app first (Devices → unit → Remove).

Nimbus Docs › Troubleshooting › Procedures › Factory Reset (X400) › Steps (X400)

Steps (X400)

  1. Hold the power button for 20 seconds until the LED blinks orange.
  2. Release the button. The unit restarts; this takes about 2 minutes.
  3. When the LED blinks teal the unit is ready to pair as new.
  4. In the app choose Devices → Add device and complete pairing.

Nimbus Docs › Troubleshooting › Procedures › Factory Reset (X400) › Verify

Verify

LED steady teal, unit Online.
