Factory Reset Procedure

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-10-25

Nimbus Docs › Troubleshooting › Procedures › Factory Reset Procedure › Before you start

Before you start

  • This erases local settings, saved Wi-Fi networks and the pairing key. Cloud data is not affected.
  • Remove the unit in the app first (Devices → unit → Remove).
  • Keep the unit on USB-C power throughout.

Nimbus Docs › Troubleshooting › Procedures › Factory Reset Procedure › Steps (X200)

Steps (X200)

  1. Hold the power button for 15 seconds until the LED blinks red.
  2. Release the button. The unit restarts; this takes about 2 minutes. Do not unplug it.
  3. When the LED blinks white the unit is ready to pair as new.
  4. In the app choose Devices → Add device and complete pairing.

Nimbus Docs › Troubleshooting › Procedures › Factory Reset Procedure › X100 note

X100 note

On the X100 the reset is menu driven: Settings → System → Reset. Holding the power button only restarts an X100.

Nimbus Docs › Troubleshooting › Procedures › Factory Reset Procedure › Verify

Verify

LED steady white, unit Online, About → Pairing key shows today’s date.
