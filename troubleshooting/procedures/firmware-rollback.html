Firmware Rollback

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-10-25

Applies to: X200.

Can I go back to 2.x?

No. Rollback from 3.x is not supported. 3.x changes the pairing and storage format, and 2.x cannot read it.

What to do instead

  • If a 3.x update left the unit unable to pair, this is expected: see Pairing (X200).
  • If the unit is unstable after an update, run the Factory Reset Procedure and update to the latest 3.x release.
