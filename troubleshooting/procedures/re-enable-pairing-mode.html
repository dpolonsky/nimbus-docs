Re-enable Pairing Mode

Product: X200 · Firmware: 3.x · Status: published · Updated: 2026-10-25

Nimbus Docs › Troubleshooting › Procedures › Re-enable Pairing Mode › Before you start

Before you start

Applies to X200, firmware 3.x. Phone Bluetooth is on, the app is signed in, the unit is powered and within 3 m. No data is erased.

Nimbus Docs › Troubleshooting › Procedures › Re-enable Pairing Mode › Steps

Steps

  1. Open the Nimbus app and go to Devices.
  2. Select the X200 (it shows Offline).
  3. Tap Enable pairing mode. The LED blinks white.
  4. Tap Pair and confirm the 6 digit code on both screens within 60 seconds.

Nimbus Docs › Troubleshooting › Procedures › Re-enable Pairing Mode › Result

Result

The LED goes steady white and the unit is Online. If the app shows E42, continue with the Factory Reset Procedure.

Nimbus Docs › Troubleshooting › Procedures › Re-enable Pairing Mode › If this procedure does not work

If this procedure does not work

  • Pairing mode times out after 60 seconds: start again.
  • The Enable button is greyed out: the update is still running, wait for the LED to stop being amber.
  • Still failing: see Pairing (X200), Steps.
