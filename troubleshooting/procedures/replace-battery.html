Replace the Backup Battery

Product: X400 · Firmware: - · Status: published · Updated: 2026-11-09

Nimbus Docs › Troubleshooting › Procedures › Replace the Backup Battery › Before you start

Before you start

Applies to X400. Only the X400 has a user replaceable backup battery, type CR2477. Replacement takes about 2 minutes.

Nimbus Docs › Troubleshooting › Procedures › Replace the Backup Battery › Steps

Steps

  1. Unplug the unit from USB-C power.
  2. Open the bottom cover with a coin.
  3. Replace the CR2477 cell with the plus side up.
  4. Close the cover and reconnect power.

Nimbus Docs › Troubleshooting › Procedures › Replace the Backup Battery › Result

Result

If it does not help, contact support.
