Before you start

Applies to all models. Support asks for model, firmware version, error code and the diagnostic log. Cases with all four are answered within 1 business day.

Nimbus Docs › Troubleshooting › Procedures › Contact Support Checklist › Steps

Steps

  1. Read the model and firmware from Devices → About.
  2. Note the error code shown in the app.
  3. Run Export Diagnostic Log.
  4. Open a case in the app under Help → Contact support.
